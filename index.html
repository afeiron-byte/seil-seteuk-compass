    생기부 점검 탭과 같은 금지어 사전·규칙으로 봅니다. 여러 학생을 한꺼번에 보려면 "생기부 점검" 탭에 나이스 엑셀을 올리세요. AI 점검은 설정 탭의 AI 연결로 동작하며 학생 이름은 가려서 보냅니다.

    생기부 점검

    나이스에서 내려받은 엑셀을 올리면 학생별로 묶어 금지어·글자 수·개인정보·반복 문장을 바로 점검하고, AI로 맞춤법·비문·서술 방식까지 살핍니다. 파일은 이 브라우저 안에서만 읽고 어디에도 저장하지 않으며, 오래 쓰지 않으면 화면에서 지워집니다.

    나이스 엑셀 파일을 여기에 끌어다 놓거나

    .xlsx · .csv · 나이스 웹 표 형식 .xls. 교과 세특·창체·행동특성 파일을 여러 개 함께 올려도 됩니다. 영역을 잘못 알아보면 파일 옆 「영역」에서 고르세요.

    금지어 사전

    점검에 쓰는 단어 목록입니다. 기본 사전에 학교 공통 목록(관리자가 관리)과 이 브라우저에서 추가한 단어를 더해 씁니다. 같은 단어는 학교 공통 목록이 우선하고, 학교에서 '제외'로 정한 단어는 기본 사전에 있어도 잡지 않습니다. 대학명·1인칭·성적·연락처 같은 형식 점검은 사전과 별도로 늘 합니다.

    단어 추가

    학교에 연결되어 있으면 학교 공통 목록에 바로 쌓입니다. 삭제와 등급 변경은 관리자가 합니다.

    학교 연결

    관리자에게 받은 접속 코드를 넣으면 학교에서 정한 계열별 가이드·금지어·글자 수 한도·AI 모델 목록을 불러옵니다. 학생 기록은 학교로 보내지 않습니다.

    내 기록 백업

    학생 기록은 이 브라우저에만 있어서 브라우저 기록을 지우거나 컴퓨터를 바꾸면 사라집니다. 가끔 백업 파일을 받아 두고, 다른 컴퓨터에서는 그 파일을 불러오세요. 파일에는 학생 이름과 기록이 들어 있으니 다른 사람과 공유하지 말고 본인만 쓰는 곳에 보관하세요. API 키와 접속 코드는 들어가지 않습니다.

    AI 연결

    API 키는 이 탭에만 있다가 탭을 닫거나 오래 쓰지 않으면 지워집니다. "기억하기"를 고른 경우에만 이 브라우저에 남습니다.

    관리자 확인

    학교 시트의 웹 앱 주소와 시트 「설정」 탭의 관리자 코드를 넣으세요. 코드는 학교 시트(Apps Script)에서 확인합니다.

    학교 시트 연결

    아직 연결하지 않음

    처음 설치 방법 (한 번만)
    1. 구글 드라이브 "세일고등학교 / 세특 나침반" 폴더의 스프레드시트 "세특 나침반 데이터"를 엽니다.
    2. 확장 프로그램 → Apps Script를 열고, 같은 폴더의 Code.gs 내용을 붙여 넣은 뒤 저장합니다.
    3. 함수 목록에서 setup을 선택해 실행하고 권한을 허용합니다. 빠진 탭과 코드가 있으면 채워집니다.
    4. 배포 → 새 배포 → 유형 "웹 앱" → 실행 사용자 "나", 액세스 "모든 사용자" → 배포 후 웹 앱 URL을 복사합니다.
    5. 위 칸에 URL과 시트 「설정」 탭의 관리자 코드를 넣고 "연결 확인"을 누릅니다.
    6. 선생님들께는 "교사용 주소 복사"로 만든 주소와 접속 코드만 알려 줍니다. 스프레드시트는 공유하지 않습니다.

    계열 가이드 데이터

    계열별 가이드는 웹페이지 코드에 넣지 않고 학교 시트 「가이드」 탭에만 둡니다. 시트를 고친 뒤 아래 버튼으로 반영하세요. 선생님들은 접속 코드로 연결할 때 받아 갑니다.
